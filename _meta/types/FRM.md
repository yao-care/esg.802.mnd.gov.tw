# FRM 類型規範 / FRM Type Specification

FRM（Form）為可填寫、提交及追蹤的資料收集表單，主要用於每月能源/排放數據收集、事件通報、異常紀錄等場景。FRM 是 ESG 數據來源的第一手文件，須支援閉環系統的欄位驗證。

## 必要章節結構

1. 【必要】表單資訊 — 表單編號、版本、分類（月報/季報/事件/其他）、填寫單位
2. 【必要】填寫說明 — 逐欄說明填寫要求、數值單位、注意事項及範例
3. 【必要】表單欄位 — 所有欄位定義，含必填標示（*）、資料型別、允許值範圍
4. 【必要】核准與簽核區段 — 填表人、主管審核、部門主管核准，各含簽名欄與日期欄
5. 【必要】附件與備註 — 應附憑證說明、備註空白區域

## 語氣與用詞規範

- 填寫說明使用條列式，每條以動詞起首（如「輸入」、「選擇」、「填入」）
- 必填欄位標示星號（*）並在說明中統一標注「* 為必填欄位」
- 欄位名稱使用名詞片語，不使用疑問句
- 數值欄位須標示單位（如「用電量 (kWh)」）
- 避免使用「請填寫」——直接描述欄位用途

## 必要元素

- 【必要】必填欄位標示 *：所有必填欄位均以星號（*）標示，頁首或說明區段統一說明「* 為必填欄位」
- 【必要】核准／簽核區段（含日期欄）：至少包含填表人姓名、簽名、日期；主管審核姓名、簽名、日期
- 【必要】填寫說明：每個欄位或欄位群組須有對應的填寫說明，避免歧義
- 【必要】表單版本與生效日期：標示於表單資訊區段
- 【必要】fields 定義（YAML schema）：merge.yaml 中需含 `fields:` 區塊，定義欄位名稱、型別、必填性

## YAML fields 範例

```yaml
fields:
  - name: reporting_month
    label: 報告月份
    type: date
    required: true
    format: "YYYY-MM"
  - name: electricity_kwh
    label: 用電量 (kWh)
    type: number
    required: true
    min: 0
  - name: remarks
    label: 備註
    type: text
    required: false
```

## 交叉引用規則

- FRM 欄位數據最終彙整至 REG 或直接引用於 RPT
- 填寫說明中若涉及計算方式，須引用對應 GDL
- 核准流程若有 SOP，須引用對應 PRO
- 若表單為事件通報，須引用 POL 中的通報政策條款

## 審查重點

- F1 **必填標示**：是否所有必填欄位均有星號標示；頁面是否有統一說明文字
- F2 **核准區段**：是否包含填表人、審核人、核准人三層簽核；是否每層均有日期欄
- F3 **欄位完整性**：fields 定義是否覆蓋所有表單欄位；必填性設定是否合理
- F4 **說明可操作性**：填寫說明是否足夠具體，操作者無需額外指示即可填寫

## 類型特定關鍵字

`必填`、`核准區段`、`填寫說明`、`簽核`、`表單欄位`、`版本`
