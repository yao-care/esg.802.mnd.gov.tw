# GDL 類型規範 / GDL Type Specification

GDL（Guideline）為非強制性的參考指引，提供 ESG 相關議題的背景知識、計算方法、公式說明及操作範例。GDL 補充 PRO 的技術細節，也為 FRM 填寫者提供方法依據，但本身不構成強制要求。

## 必要章節結構

1. 【必要】目的與適用範圍 — 說明此指引解決什麼問題、適用哪些場景及使用對象（如：碳盤查人員、ESG 報告撰寫者）
2. 【必要】背景知識／理論基礎 — 提供理解此指引所需的背景資訊、相關概念定義及引用的國際標準或學術依據
3. 【必要】方法／公式／步驟 — 核心內容：計算公式、判斷準則、操作步驟或決策流程，以精確且可重現的方式呈現
4. 【必要】範例 — 至少一個具體的 worked example，展示方法或公式的實際應用（含輸入數據、計算過程、結果）
5. 【必要】參考資料 — 列出所有引用的文獻、標準、法規、網站，含版本/日期資訊

## 語氣與用詞規範

- 背景知識與方法說明使用說明性語氣（「排放因子是指…」、「計算方式為…」）
- 步驟說明使用動詞起首（「計算」、「查詢」、「代入」、「記錄」）
- 數學公式使用行內格式（`E = A × EF`）或區塊格式（使用程式碼區塊）
- 避免使用 shall/should；GDL 為建議性指引，使用「建議」、「可」、「通常」
- 單位必須明確標示（tCO₂e/單位、kWh、公升/年等）

## 必要元素

- 【必要】參考資料來源：參考資料章節必須列出所有引用的文件，含完整書目資訊（作者/機構、標題、版本/年份、URL 或 ISBN）
- 【必要】計算公式或方法步驟：方法章節中必須包含可重現的計算公式或明確的操作步驟，不可僅有概念描述
- 【建議】範例（worked example）：強烈建議提供一個完整的計算範例，含假設的輸入數據、逐步計算過程及最終結果，幫助使用者驗證自己的計算

## 公式呈現格式範例

**公式：**
```
排放量 (tCO₂e) = 活動數據 (單位) × 排放係數 (tCO₂e/單位)
```

**範例：**
- 活動數據：用電量 = 100,000 kWh
- 排放係數：0.494 kgCO₂e/kWh（2024 年台灣電力排放係數，經濟部能源署）
- 排放量 = 100,000 × 0.494 / 1000 = **49.4 tCO₂e**

## 交叉引用規則

- GDL 的方法被 PRO 採用時，PRO 在「相關文件」中引用此 GDL 識別碼
- GDL 中的係數若匯整為清單，連結至對應的 REG（排放係數登記冊）
- GDL 若說明如何填寫特定 FRM，在方法章節引用 FRM 文件識別碼
- 若背景知識涉及法規要求，引用 STD 文件識別碼

## 審查重點

- G1 **公式／方法**：方法章節是否包含可重現的計算公式或步驟；公式中的變數是否均有定義
- G2 **參考來源**：參考資料是否完整（含版本和日期）；引用的係數是否為現行有效版本
- G3 **範例完整性**：worked example 是否包含輸入數據、計算過程及結果；是否可重現
- G4 **技術準確性**：公式和係數是否符合現行國際標準（ISO 14064-1、IPCC 等）

## 類型特定關鍵字

`參考`、`公式`、`範例`、`計算方法`、`排放係數`、`worked example`、`背景知識`
