# PLN 類型規範 / PLN Type Specification

PLN（Plan）為行動計畫文件，用於記錄 ESG 目標的具體行動方案、負責人、期限及追蹤狀態。PLN 是政策（POL）與實際執行之間的橋接文件，須以結構化行動表格呈現並定期檢討。

## 必要章節結構

1. 【必要】目的與範圍 — 說明本計畫要解決的問題或達成的目標、適用範圍及計畫週期
2. 【必要】行動方案表格 — 以結構化表格列出所有行動項目，含行動描述、負責人、期限、狀態欄
3. 【必要】負責人與期限 — 說明責任分工原則；若多人共同負責，明確指定一位主責者
4. 【必要】追蹤與檢討機制 — 說明進度更新頻率、檢討會議安排及異常升報流程
5. 【必要】相關文件 — 列出觸發此計畫的 POL/PRO，以及計畫執行產生的 FRM/REG

## 語氣與用詞規範

- 行動方案使用動詞起首（「建置」、「導入」、「培訓」、「驗證」）
- 期限使用具體日期（「2026-06-30」）或季度（「2026 Q2」），不使用「盡快」或「近期」
- 狀態欄使用統一代碼：`待啟動` / `進行中` / `已完成` / `延遲` / `取消`
- 負責人使用職稱（「ESG 組長」），不使用個人姓名
- 計畫描述使用現在式（「每季執行碳盤查數據驗證」）

## 必要元素

- 【必要】行動表格（含負責人、期限、狀態欄）：表格至少包含欄位：行動項目、負責人、目標完成日期、狀態、備註
- 【必要】時程或甘特圖引用：對於跨季度的計畫，須包含 Mermaid gantt 圖或時程總覽表；單季計畫可用行動表格的日期欄替代
- 【必要】計畫總目標：目的與範圍章節中須陳述量化或可驗證的總目標（如「2026 年底前達成範疇二減排 10%」）
- 【必要】最後更新日期：文件標頭或追蹤章節中標示上次更新日期

## 行動表格格式範例

| 行動項目 | 負責人 | 目標完成日期 | 狀態 | 備註 |
|---------|--------|------------|------|------|
| 建置月報收集系統 | ESG 組長 | 2026-03-31 | 已完成 | |
| 導入 ISO 14064 查證 | ESG 主管 | 2026-09-30 | 進行中 | 查證機構已確認 |

## 交叉引用規則

- 目的與範圍章節須引用觸發此計畫的 POL 或 PRO 文件識別碼
- 行動項目若需要填寫表單，引用 FRM 文件識別碼
- 計畫執行結果的紀錄引用 REG 文件識別碼
- 若計畫涉及外部標準要求，引用 STD 文件識別碼

## 審查重點

- PL1 **行動表格完整**：表格是否包含所有必要欄位（行動項目、負責人、期限、狀態）；是否有空白欄位
- PL2 **負責人明確**：每個行動項目是否指定單一主責者；職稱描述是否清楚
- PL3 **期限可驗證**：期限是否為具體日期或季度；是否有模糊描述
- PL4 **追蹤機制**：是否說明更新頻率；是否有異常升報流程
- PL5 **總目標量化**：計畫的整體目標是否可量測、可驗證

## 類型特定關鍵字

`行動表格`、`負責人`、`期限`、`狀態`、`追蹤`、`甘特圖`、`計畫週期`
