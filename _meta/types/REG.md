# REG 類型規範 / REG Type Specification

REG（Record/Register）為持續維護的紀錄冊或登記表，用於追蹤排放源清單、法規清單、供應商紀錄、設備清冊等隨時間累積的結構化資料。REG 與 FRM 的區別在於：FRM 為單次填寫提交，REG 為持續累積更新。

## 必要章節結構

1. 【必要】紀錄目的 — 說明此登記冊追蹤什麼資訊、為什麼需要追蹤、使用對象與使用場景
2. 【必要】紀錄格式（表格欄位定義） — 定義登記冊的表格結構：每個欄位的名稱、說明、資料型別、必填性
3. 【必要】更新頻率與責任人 — 說明何時新增/更新/刪除記錄、由誰執行、誰核准變更
4. 【必要】保存與歸檔 — 說明紀錄保存年限、歸檔位置、備份策略及銷毀規定

## 語氣與用詞規範

- 欄位定義使用名詞片語（「排放源名稱」而非「請填寫排放源的名稱」）
- 更新頻率使用具體頻率（「每月最後一個工作日前」）而非模糊描述
- 責任人使用職稱，不使用個人姓名
- 保存年限明確數字（「保存 7 年」），不使用「依法規」等模糊說法（但可補充引用依據）

## 必要元素

- 【必要】表格格式定義：以 Markdown 表格或有序列表定義每個欄位，包含欄位名稱、說明、型別（文字/數值/日期/選項）、是否必填
- 【必要】更新頻率聲明：更新頻率與責任人章節必須明確聲明更新頻率（如「每月」、「每季」、「即時」）及負責更新的角色
- 【必要】目前版本的登記資料：REG 文件主體包含現行的登記表（實際數據）；新文件可為空表格，但欄位定義必須完整
- 【必要】保存年限數字：保存與歸檔章節必須明確數字

## 欄位定義格式範例

| 欄位名稱 | 說明 | 型別 | 必填 |
|---------|------|------|------|
| 排放源 ID | 排放源的唯一識別碼（格式 ES-XXX） | 文字 | 是 |
| 排放源名稱 | 中文名稱 | 文字 | 是 |
| 排放類別 | 類別 1 / 類別 2 / 類別 3 | 選項 | 是 |
| 排放係數 | 使用的排放係數數值（tCO₂e/單位） | 數值 | 是 |
| 係數來源 | 排放係數引用來源（含版本） | 文字 | 是 |
| 啟用日期 | 此排放源開始追蹤的日期 | 日期 | 是 |
| 停用日期 | 若已停用，填入停用日期 | 日期 | 否 |
| 備註 | 補充說明 | 文字 | 否 |

## 交叉引用規則

- REG 中的資料來源應引用提供原始數據的 FRM 表單識別碼
- REG 被 RPT 引用時，在排放數據章節說明「排放源清單詳見 `REG-XXX`」
- 更新程序若有正式流程，引用對應的 PRO 文件識別碼
- 排放係數 REG 須引用 GDL-001 作為係數選取依據

## 審查重點

- RG1 **表格格式**：欄位定義是否完整（名稱、說明、型別、必填性）；格式是否為 Markdown 表格
- RG2 **更新頻率**：是否明確聲明更新頻率；是否指定責任人職稱
- RG3 **保存年限**：是否有具體的年限數字；是否說明歸檔位置
- RG4 **資料完整性**：現行登記表中是否有遺漏必填欄位的記錄

## 類型特定關鍵字

`表格格式`、`更新頻率`、`責任人`、`保存年限`、`登記冊`、`欄位定義`、`歸檔`
