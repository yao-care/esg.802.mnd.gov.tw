# STD 類型規範 / STD Type Specification

STD（Standard）為法規標準對應文件，記錄外部法規、國際標準或主管機關要求的條款摘錄，以及組織對應的合規說明與差異分析。STD 是稽核引文的核心依據。

## 必要章節結構

1. 【必要】標準來源與版本 — 列明法規名稱、發布機關、條款號、版本日期及取得來源
2. 【必要】適用條款摘錄 — 逐條引用與本組織相關的法規或標準條款原文（或官方中譯文）
3. 【必要】組織對應說明 — 針對每條摘錄條款，說明組織如何滿足要求（對應措施、文件、系統）
4. 【必要】合規差異分析 — 識別尚未完全符合的條款，說明差異原因及預計達標時程
5. 【必要】相關文件 — 列出引用此 STD 的 POL、PRO、PLN 文件識別碼

## 語氣與用詞規範

- 條款摘錄使用引用格式（`>` Markdown blockquote）並標注條款來源
- 組織對應說明使用現在式陳述事實（「本組織每年執行 GHG 盤查…」）
- 合規狀態標示使用統一符號：`✅ 合規` / `⚠️ 部分合規` / `❌ 不合規` / `N/A 不適用`
- 禁止在 STD 中加入主觀評論；只陳述客觀對應事實
- 條款號格式遵循來源標準的原始格式（如 ISO 14064-1 第 5.2.3 條、《溫室氣體盤查議定書》第 4 章）

## 必要元素

- 【必要】來源歸屬（法規名稱、條款號、版本日期）：每條摘錄必須在引文前標示完整的來源資訊
- 【必要】合規狀態標示：組織對應說明章節的每條條款對應須有合規狀態標示
- 【必要】差異分析完整性：合規差異分析章節須涵蓋所有摘錄條款（即使全部合規，也需陳述「符合，差異為零」）
- 【必要】版本追蹤：STD 文件本身的版本記錄，及所追蹤的外部法規版本資訊

## 條款摘錄格式範例

```markdown
### 5.2.1 組織邊界

**來源：** ISO 14064-1:2018 第 5.2.1 條
**狀態：** ✅ 合規

> 組織應選擇並使用合併方法或股權比例法，建立其組織邊界。
> 若組織採用合併方法，則應進一步選擇財務控制或營運控制方法。

**對應說明：** 本組織採用財務控制方法，已於 RPT-001 第 3 章定義組織邊界並列明所有納入的營運實體。
```

## 交叉引用規則

- 每條對應說明引用實際履行措施的 POL 或 PRO 文件識別碼
- 如有 PLN 計畫處理不合規差異，在差異分析中引用對應 PLN
- 被 RPT 引用時，在排放數據章節引用此 STD 說明適用標準
- 跨標準引用時（如同時引用 ISO 14064-1 和金管會準則），各建立獨立 STD 文件

## 審查重點

- S1 **來源歸屬**：每條摘錄是否有完整的法規名稱、條款號及版本日期；格式是否一致
- S2 **合規分析**：是否每條條款都有合規狀態標示；差異分析是否具體說明原因和達標計畫
- S3 **條款時效性**：引用的法規版本是否為現行有效版本；是否有過期法規
- S4 **對應完整性**：組織對應說明是否覆蓋所有摘錄條款；是否有條款僅摘錄但無說明

## 類型特定關鍵字

`條款`、`要求`、`合規`、`法規`、`標準來源`、`差異分析`、`版本日期`
