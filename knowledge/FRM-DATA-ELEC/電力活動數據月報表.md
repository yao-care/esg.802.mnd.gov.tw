# 電力活動數據月報表

**表單編號：** FRM-DATA-ELEC
**表單版本：** 1.0
**管理單位：** 永續發展室
**填報單位：** 工程室

---

## 1. 表單資訊

| 欄位 | 說明 |
|------|------|
| **用途** | 蒐集國軍高雄總醫院院區各電號每月用電度數，以及應排除之租用單位與721營站用電量，供年度溫室氣體盤查類別2外購電力排放量計算使用 |
| **填報頻率** | 每月填報，於次月10日前提交永續發展室 |
| **涵蓋電號** | 18323050016、18323050118、18323051142、18323051197（共4個電號） |
| **相關程序** | PRO-GHG-INV 溫室氣體盤查作業程序書 |
| **相關指引** | GDL-CALC-METHOD 溫室氣體排放量計算方法指引 |

---

## 2. 填寫說明

| 欄位名稱 | 填寫說明 |
|---------|---------|
| **填報月份** | 填寫電費單所代表之月份，格式：YYYY-MM（例：2025-03）。若電費單統計週期跨年份，依天數比例拆分後填入正確月份。 |
| **電號** | 從下拉選單選擇台電電號。本院共有4個電號，每個電號各填一列。電號說明如下：<br>- 18323050016：院區主要用電電號，每月統計（前月1日至當月1日）<br>- 18323050118：院區次要電號，每月統計（前月1日至當月1日）<br>- 18323051142：院區電號，每雙月統計（前兩月至當月）<br>- 18323051197：院區電號，每雙月統計（前兩月至當月） |
| **用電度數** | 填入台電電費清單記載之該電號當期用電度數（kWh，最多4位小數）。若統計週期跨年份，依天數比例拆分後填入各年份部分。 |
| **計費區間** | 填入台電電費清單所載之計費起始日至截止日，格式：YYYY-MM-DD 至 YYYY-MM-DD（例：2025-12-01至2026-01-01）。 |
| **排除度數(租用+721營站)** | 非必填。填入本月份應從該電號扣除之租用單位與721營站用電度數合計。依「委外業務水電費統計表」及「營站/自動販賣機電費統計表」計算。若無排除量填0。 |
| **電費單編號** | 填入台電電費清單之編號或序號，作為原始憑證識別。 |

## 5. 附件與備註

### 5.1 必要附件

提交本表單時，請同時提供以下文件之電子掃描檔：

| 文件 | 說明 |
|------|------|
| 台電電費清單 | 各電號當月電費清單（4份）|
| 委外業務水電費統計表 | 列明各租用單位當月用電度數 |
| 營站/自動販賣機電費統計表 | 721營站當月用電度數 |

### 5.2 電號統計週期說明

| 電號 | 計費週期 | 抄表頻率 | 跨年份處理 |
|------|---------|---------|---------|
| 18323050016 | 前月1日至當月1日 | 每月 | 依天數比例拆分 |
| 18323050118 | 前月1日至當月1日 | 每月 | 依天數比例拆分 |
| 18323051142 | 前兩月月初至當月月初 | 每雙月 | 依天數比例拆分 |
| 18323051197 | 前兩月月初至當月月初 | 每雙月 | 依天數比例拆分 |

> 假設台電公司不將統計週期最後一日之用電度數計入。

### 5.3 排除量計算說明

2025年應排除之租用單位（共16個）：

| 類型 | 單位名稱 |
|------|---------|
| 商業服務 | 居家護理販賣部、萊爾富(醫療)、萊爾富(軍陣)、合作金庫、理髮部 |
| 保全/清潔 | 保全、清潔公司、壽元治洗衣部 |
| 其他服務 | 太平間(九易)、自助洗衣 |
| 電信 | 台哥大強波器、遠傳電信強波器、中華電信強波器 |
| 醫療相關 | 放射腫瘤科、院區宿舍 |
| 工程 | 整修工程 |

以及721營站用電（電費非由本院繳納）。

排除量認定方式：假設「委外業務水電費統計表」之各租用單位用電度數統計週期，均為前一月份第一日至最後一日。

### 5.4 年度用電彙整

年度用電量彙整公式：

```
本院年度淨用電量 = Σ（各電號12個月用電度數）- Σ（各月排除度數）
```

2025年彙整結果：
- 台電統計用電總量：15,691,527.7081度（含需排除量）
- 排除電量（租用+721營站）：596,999.0000度
- 本院年度淨用電量：15,094,528.7081度

### 5.5 數據保存

- 本表單（含電費清單掃描檔）由永續發展室統一存檔，保存期限6年
- 台電電費清單紙本由工程室保管，保存期限6年
