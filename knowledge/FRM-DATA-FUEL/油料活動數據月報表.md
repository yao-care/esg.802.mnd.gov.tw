# 油料活動數據月報表

**表單編號：** FRM-DATA-FUEL
**表單版本：** 1.0
**管理單位：** 永續發展室
**填報單位：** 醫勤組（天然氣、LPG）、工程室（柴油發電機）、駕駛班（公務車燃油、尿素）

---

## 1. 表單資訊

| 欄位 | 說明 |
|------|------|
| **用途** | 蒐集國軍高雄總醫院每月油料（固定源及移動源燃料）消耗活動數據，供年度溫室氣體盤查計算使用 |
| **填報頻率** | 每月填報，於次月5日前提交永續發展室 |
| **涵蓋排放源** | 固定源：天然氣、液化石油氣、柴油（緊急發電機）；移動源：車用汽油（公務車）、車用柴油（公務車）、車用尿素 |
| **相關程序** | PRO-GHG-INV 溫室氣體盤查作業程序書 |
| **相關指引** | GDL-CALC-METHOD 溫室氣體排放量計算方法指引 |

---

## 2. 填寫說明

| 欄位名稱 | 填寫說明 |
|---------|---------|
| **填報月份** | 填寫數據所屬月份，格式：YYYY-MM（例：2025-03）。天然氣、LPG依帳單統計週期認定月份；跨年份帳單依天數比例拆分。 |
| **燃料種類** | 從下拉選單選擇：天然氣 / 液化石油氣 / 柴油(發電機) / 車用汽油 / 車用柴油 / 車用尿素。每種燃料填一列。 |
| **使用設施** | 說明燃料使用設施，例如：廚房瓦斯爐（天然氣，表號F0877131）、廚房瓦斯爐（LPG）、緊急發電機、公務車-救護車、公務車-指揮車 等。 |
| **使用量** | 填入本月實際使用量（數字，最多4位小數）。天然氣填入帳單統計度數（m³）；LPG填入採購重量（公斤）；柴油填入採購體積（公升）；汽油填入加油量（公升）；柴油（公務車）填入加油量（公升）；尿素填入採購體積（公升）。 |
| **單位** | 從下拉選單選擇：度(m³) / 公斤 / 公升。天然氣選「度(m³)」；LPG選「公斤」；其他選「公升」。 |
| **發票/憑證編號** | 填入對應發票號碼、繳費單號或核銷文件編號，作為原始數據憑證。若單月有多張發票，可在備註欄列出，此欄填入主要憑證編號。 |
| **備註** | 非必填。可填寫異常說明（如：本月無採購、發電機備油充足）、跨年份天數計算說明等。 |

## 5. 附件與備註

### 5.1 必要附件

提交本表單時，請同時提供以下原始憑證之電子掃描檔：

| 燃料種類 | 應附憑證 |
|---------|---------|
| 天然氣 | 欣高石油氣公司月帳單（表號F0877131及C0008471） |
| 液化石油氣 | 採購發票 |
| 柴油（發電機）| 採購發票或油料領用單 |
| 車用汽油 | 加油發票或油料費用核銷文件 |
| 車用柴油 | 加油發票或油料費用核銷文件 |
| 車用尿素 | 採購發票（含SDS安全資料表，首次採購時提供）|

### 5.2 特殊情況說明

**無採購月份：**
- 若當月無採購（如緊急發電機本年度無用油），使用量填「0.0000」，備註說明「本月（年）無採購，油料儲備充足」
- 仍須填報並提交，確保紀錄完整

**天然氣帳單跨年份計算：**
- 帳單統計週期若跨越年份（如12月帳單涵蓋12/25至次年1/25），依天數比例拆分：
  - 當年份用量 = 帳單總度數 × 當年份天數 ÷ 帳單總天數
  - 次年份用量 = 帳單總度數 × 次年份天數 ÷ 帳單總天數
- 在備註欄說明計算方式

**車用尿素：**
- 填入採購發票之購買量（公升）
- 備註欄填入尿素產品名稱及SDS記載之濃度與比重（用於驗證計算）

### 5.3 數據保存

- 本表單（含電子憑證）由永續發展室統一存檔，保存期限6年
- 原始紙本憑證由各業務單位保管，保存期限6年
