# 氣體鋼瓶及滅火器紀錄表

**表單編號：** FRM-DATA-GAS
**表單版本：** 1.0
**管理單位：** 永續發展室
**填報單位：** 職安室（CO2鋼瓶、混合氣鋼瓶、消防設備、GCB、噴罐）；衛保室（麻醉氣體）

---

## 1. 表單資訊

| 欄位 | 說明 |
|------|------|
| **用途** | 紀錄國軍高雄總醫院院區內麻醉氣體、各類氣體鋼瓶、消防設備（含滅火器）、GCB瓦斯斷路器及噴罐之採購或維修補充量，供年度溫室氣體盤查類別1逸散源計算使用 |
| **填報頻率** | 每月填報（麻醉氣體：依藥衛材管理系統每月請領量統計；其他：依採購事件），次月5日前提交永續發展室 |
| **涵蓋排放源** | 麻醉氣體（Sevoflurane、Isoflurane）、CO2氣體鋼瓶、混合氣體鋼瓶、CO2滅火器、環保氣體滅火器(HFC-227ea)、GCB瓦斯斷路器(SF6)、噴罐 |
| **相關程序** | PRO-GHG-INV 溫室氣體盤查作業程序書 |
| **相關指引** | GDL-CALC-METHOD 溫室氣體排放量計算方法指引 |

## 2. 填寫說明

| 欄位名稱 | 填寫說明 |
|---------|---------|
| **紀錄日期** | 填入採購發票日期或藥品請領日期，格式：YYYY-MM-DD。麻醉氣體採藥衛材管理系統登錄日期（注意：藥衛材管理系統登錄時間與實際涵蓋時間可能存在差異，2025年度實際涵蓋2024年12月24日至2025年12月22日）。 |
| **類別** | 從下拉選單選擇：麻醉氣體 / CO2氣體鋼瓶 / 混合氣體鋼瓶 / CO2滅火器 / 環保氣體滅火器(HFC-227ea) / GCB瓦斯斷路器(SF6) / 噴罐。 |
| **品名/藥材代碼** | 填入品名或院內藥材代碼。麻醉氣體填入藥材代碼（如Sevoflurane未特定代碼則填品名）；CO2鋼瓶填藥材代碼（如Z05、Z051、BH02）；混合鋼瓶填藥材代碼（如M2625）；消防設備填品名及規格。 |
| **數量(支/瓶)** | 填入本次採購或補充之支數/瓶數（整數）。麻醉氣體以瓶（ml）計算，換算為kg時另行計算。 |
| **氣體填充量(kg/支)** | 填入每支/瓶之溫室氣體填充量（公斤）。CO2鋼瓶：依規格（6M3=20kg、500L=2kg）；麻醉氣體：依購買ml數及比重換算為kg。**僅計算溫室氣體成分**（如混合氣體鋼瓶只填CO2填充量）。 |
| **合計填充量(kg)** | 自動計算 = 數量 × 氣體填充量(kg/支)。應手動確認計算正確。 |
| **數據來源** | 說明活動數據取得途徑，例如：採購發票、藥衛材管理系統、瓶身資訊、廠商資料、消防安全設備檢修申報書等。 |

### 5.4 Sevoflurane比重換算說明

Sevoflurane仿單記載比重範圍1.520~1.525，本院採用最大值1.525進行換算：

```
換算公式：請領量(mL) × 1.525(g/mL) ÷ 1,000 = kg

範例：86,000 mL × 1.525 ÷ 1,000 = 131.15 kg
排放量：131.15 kg × 144 ÷ 1,000 = 18.8856 tCO2e
```

### 5.5 麻醉氣體數據時間說明

藥衛材管理系統登錄時間因素，活動數據實際涵蓋時間為前一年12月24日至當年12月22日（而非曆年1月1日至12月31日）。在填報時應標明登錄日期，由永續發展室統一換算至盤查年度。
