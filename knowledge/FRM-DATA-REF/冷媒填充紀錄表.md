# 冷媒填充紀錄表

**表單編號：** FRM-DATA-REF
**表單版本：** 1.0
**管理單位：** 永續發展室
**填報單位：** 工程室

---

## 1. 表單資訊

| 欄位 | 說明 |
|------|------|
| **用途** | 紀錄國軍高雄總醫院院區內各類冷媒設備之冷媒填充事件（新購設備初始填充及既有設備維修補充），供年度溫室氣體盤查類別1逸散源冷媒排放量計算使用 |
| **填報頻率** | 事件型填報：每次冷媒填充事件發生後3個工作日內填報 |
| **涵蓋設備** | 冷氣/冰水主機、飲水機、除濕機、雜項冷藏設備、醫用冷藏冷凍設備、製冰機、汽車空調、乾燥機 |
| **相關程序** | PRO-GHG-INV 溫室氣體盤查作業程序書 |
| **相關指引** | GDL-CALC-METHOD 溫室氣體排放量計算方法指引（冷媒GWP值） |

## 2. 填寫說明

| 欄位名稱 | 填寫說明 |
|---------|---------|
| **填充日期** | 填入冷媒實際填充操作日期，格式：YYYY-MM-DD（例：2025-10-17）。 |
| **設備類別** | 從下拉選單選擇設備類型：冷氣/冰水主機 / 飲水機 / 除濕機 / 雜項冷藏設備 / 醫用冷藏冷凍設備 / 製冰機 / 汽車空調 / 乾燥機。 |
| **設備編號/位置** | 填入設備財產編號或明確位置描述，例如：「門診大樓3F-A001」、「急診冷氣主機B棟」、「大樓冰水主機KLTW-400D-3DLJ2」。若無財產編號，填入位置足以識別設備即可。 |
| **冷媒種類** | 從下拉選單選擇：R-32 / R-134a / R-401A / R-410A / R-404A / R-452A / R-513A / R-449A。若設備使用其他冷媒種類（如R-290、R-600a），請填入備註欄，**不選此欄**（這些非管制溫室氣體不納入盤查計算）。 |
| **填充量(kg)** | 填入本次實際填充之冷媒重量（公斤，最多4位小數）。新購設備填入銘牌或出廠資料之原始填充量；維修補充填入實際補充量。若維修紀錄無法確認實際補充量，採計該設備銘牌之原始填充量。 |
| **填充原因** | 從下拉選單選擇：新購設備（設備首次填充）/ 維修補充（既有設備維修時補充）。 |
| **施工人員** | 非必填。填入執行冷媒填充之技術人員姓名或廠商名稱，例如：「工程室王技士」、「XXX冷氣技術股份有限公司」。 |

## 5. 附件與備註

### 5.1 必要附件

每筆冷媒填充事件應附以下文件之電子掃描檔：

| 情況 | 應附文件 |
|------|---------|
| 新購設備 | 採購發票（含冷媒種類及填充量資訊）、設備銘牌照片或廠商出廠規格書 |
| 維修補充 | 採購發票（冷媒購買）或維修廠商工作單（含補充量）、設備銘牌照片（若無法確認實際補充量時） |

### 5.2 GWP值快速查詢

| 冷媒種類 | GWP值（AR6） | 排放量計算 |
|---------|------------|---------|
| R-32 | 771 | 填充量(kg) × 771 ÷ 1,000 = tCO2e |
| R-134a | 1,530 | 填充量(kg) × 1,530 ÷ 1,000 = tCO2e |
| R-401A | 1,263 | 填充量(kg) × 1,263 ÷ 1,000 = tCO2e |
| R-410A | 2,256 | 填充量(kg) × 2,256 ÷ 1,000 = tCO2e |
| R-404A | 4,728 | 填充量(kg) × 4,728 ÷ 1,000 = tCO2e |
| R-452A | 2,292 | 填充量(kg) × 2,292 ÷ 1,000 = tCO2e |
| R-513A | 673 | 填充量(kg) × 673 ÷ 1,000 = tCO2e |
| R-449A | 1,498 | 填充量(kg) × 1,498 ÷ 1,000 = tCO2e |

### 5.3 不納入盤查之冷媒種類

以下冷媒種類因非管制溫室氣體或IPCC未公告GWP，請在備註欄記錄，**不填入冷媒種類欄位**（不計入盤查排放量）：

| 冷媒種類 | 不納入原因 |
|---------|---------|
| R-600a（異丁烷）| 非管制之溫室氣體 |
| R-290（丙烷）| 天然冷媒(HC)，短壽命氣體，IPCC未公告GWP |
| R-170（乙烷）| 天然冷媒(HC)，短壽命氣體，IPCC未公告GWP |
