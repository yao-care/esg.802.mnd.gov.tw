# 能源使用監測月報表

**表單編號：** FRM-ENERGY-MON
**表單版本：** 1.0
**管理單位：** 工程室
**填報單位：** 工程室

---

## 1. 表單資訊

| 欄位 | 說明 |
|------|------|
| **用途** | 記錄國軍高雄總醫院每月電力使用情況，追蹤節能績效，供年度ESG報告及節能減碳計畫執行成效評估使用 |
| **填報頻率** | 每月填報，於次月15日前提交永續發展室 |
| **數據來源** | 台電電費單（參照 FRM-DATA-ELEC 月報彙整結果）|
| **相關程序** | PLN-ENERGY 節能減碳行動計畫 |
| **相關表單** | FRM-DATA-ELEC（電力活動數據月報表，詳細電號數據來源）|

---

## 2. 填寫說明

| 欄位名稱 | 填寫說明 |
|---------|---------|
| **填報月份** | 填寫本報表所代表之月份，格式：YYYY-MM（例：2026-05）|
| **當月總用電(度)** | 填入本月台電計費統計之院區四個電號用電度數加總（含租用單位及721營站）。數值應與 FRM-DATA-ELEC 當月合計一致。 |
| **排除用電(度)** | 填入本月依委外業務水電費統計表及營站電費統計表，應從總用電量中扣除之度數。若無排除量填0。 |
| **本院淨用電(度)** | 自動計算欄位：本院淨用電 = 當月總用電 - 排除用電。請核對計算結果正確性。 |
| **上月用電(度)** | 填入上一個月份之本院淨用電度數，供環比分析。 |
| **去年同月用電(度)** | 填入去年同一月份之本院淨用電度數，供年比分析。 |
| **備註(異常說明)** | 若本月用電量與上月或去年同月相比差異超過5%，須說明原因（如：大型設備啟用、施工用電、天氣異常等）。|

---

## 3. 表單欄位

| 欄位名稱 | 類型 | 必填 | 說明 |
|---------|------|------|------|
| 填報月份* | 文字 | 是 | 格式YYYY-MM，例：2026-05 |
| 當月總用電(度)* | 數字 | 是 | 四個電號用電合計（含排除量）|
| 排除用電(度) | 數字 | 否 | 租用單位及721營站用電，無則填0 |
| 本院淨用電(度)* | 數字 | 是 | 當月總用電 - 排除用電 |
| 上月用電(度) | 數字 | 否 | 上月本院淨用電度數，供環比 |
| 去年同月用電(度) | 數字 | 否 | 去年同月本院淨用電度數，供年比 |
| 備註(異常說明) | 文字區塊 | 否 | 差異超過5%時說明原因 |

> \* 標記欄位為必填

### 3.1 參考比較分析表

填報時可依以下欄位自行計算比較差異：

| 比較項目 | 計算公式 | 警示門檻 |
|---------|---------|---------|
| 與上月環比增減 | (本月淨用電 - 上月用電) ÷ 上月用電 × 100% | 差異 > ±5% 須說明 |
| 與去年同月年比增減 | (本月淨用電 - 去年同月) ÷ 去年同月 × 100% | 差異 > ±5% 須說明 |

## 5. 附件與備註

### 5.1 必要附件

提交本表單時，請確認以下資料已完成：

| 文件 | 說明 |
|------|------|
| FRM-DATA-ELEC（當月）| 本月四個電號詳細用電數據，為本表單總用電依據 |

### 5.2 年度彙整

本表單每月數據由永續發展室彙整為年度報表，作為 RPT-GHG 年度電力排放量計算基礎：

```
年度本院淨用電量 = Σ（1月至12月本院淨用電度數）
年度電力排放量（tCO2e）= 年度淨用電量 × 電力排碳係數 ÷ 1,000
```

### 5.3 數據保存

- 本表單由永續發展室統一存檔，保存期限6年
- 作為年度溫室氣體盤查支持文件保管
