# 職災／異常事件通報表

**表單編號：** FRM-INCIDENT
**表單版本：** 1.0
**管理單位：** 環安衛室
**填報對象：** 全體員工

---

## 1. 表單資訊

| 欄位 | 說明 |
|------|------|
| **用途** | 蒐集國軍高雄總醫院職業災害及工作相關異常事件通報資訊，供環安衛室執行事件調查、統計分析及主管機關申報使用 |
| **填報時機** | 發生職業災害或異常事件後 **24小時內** 提交環安衛室 |
| **緊急通報** | 下列情況須於 **1小時內** 電話通報環安衛室：針扎/血液體液暴露、化療藥外洩接觸、重大跌倒（需急診）、暴力傷害 |
| **相關程序** | PRO-OHS 職業安全衛生管理程序書 |
| **主管法規** | 職業安全衛生法第37條 |

| 欄位名稱 | 填寫說明 |
|---------|---------|
| **事件日期\*** | 填寫事件發生之日期，格式：YYYY-MM-DD |
| **事件時間\*** | 填寫事件發生之時間，格式：HH:MM（24小時制，例：14:30）|

## 5. 附件與備註

### 5.1 後續處理流程

環安衛室收到通報後，將依 PRO-OHS 執行以下作業：

| 步驟 | 時效 | 說明 |
|------|------|------|
| 初步評估 | 1個工作日內 | 確認事件嚴重度及是否需立即採取管控 |
| 初步調查報告 | 72小時內 | 訪談、現場勘查、根本原因分析 |
| 法定申報（重大職災）| 8小時內電話、24小時內書面 | 依職安法第37條向勞動部及檢察署申報 |
| 矯正預防措施 | 7個工作日內提出 | 短中長期改善行動 |
| 職安衛委員會報告 | 次季委員會 | 納入定期審查 |

### 5.2 特殊事件處理說明

**針扎/血液體液暴露：**
1. 立即以清水和肥皂沖洗傷口（勿擠壓）至少5分鐘
2. 通報環安衛室及感染管制師（辦公時間外聯繫值班護理長）
3. 評估暴露源（病患血清學狀況）
4. 72小時內至職業醫學科評估預防性用藥

**化療藥品外洩/接觸：**
1. 立即離開暴露區域
2. 脫除汙染衣物（按化療外洩處理程序）
3. 用清水大量沖洗接觸部位至少15分鐘
4. 至急診評估

### 5.3 資料保存

- 本表單（含調查報告）由環安衛室統一存檔，保存期限 5 年
- 重大職災之申報文件保存期限與申報記錄相同，最少 5 年
