## 2. 填寫說明

| 欄位名稱 | 填寫說明 |
|---------|---------|
| **里程碑名稱*** | 填寫具體里程碑名稱，應可明確識別工程階段。例：「基礎工程完工」、「EEWH 申請送件」、「竣工驗收」。 |
| **預定完成日*** | 填寫合約或計畫排定之里程碑完成日期，格式：YYYY-MM-DD。 |
| **實際完成日** | 非必填。里程碑實際完成後填入，格式：YYYY-MM-DD。若尚未完成則留空。 |
| **狀態*** | 從下拉選單選擇目前狀態：未開始 / 進行中 / 完成 / 延遲。狀態定義見第 2.1 節。 |
| **負責單位*** | 填寫該里程碑之主責單位（如工程室、承攬商名稱）。 |
| **備註** | 非必填。填寫里程碑延遲原因、變更說明或其他注意事項。 |

### 2.1 狀態定義

| 狀態 | 定義 |
|------|------|
| **未開始** | 尚未啟動，在預定時間前 |
| **進行中** | 已開始執行，尚未完成 |
| **完成** | 里程碑已如期或提前完成，並通過驗收確認 |
| **延遲** | 超過預定完成日仍未完成，或預期將延遲完成 |

## 5. 附件與備註

### 5.1 典型里程碑清單（參考）

下列為醫院建案常見里程碑，供填報時參考：

| 階段 | 典型里程碑 |
|------|---------|
| 規劃設計 | 建案 ESG 評估完成、設計圖說核定、EEWH 可行性評估完成 |
| 招標發包 | 招標公告發布、承攬商決標、合約簽訂 |
| 施工準備 | 承攬商安全告知完成、工地安全圍籬設置完成、FRM-MILESTONE 追蹤表建立 |
| 施工執行 | 基礎工程完工、結構體完工、機電工程完工、裝修完工 |
| 收尾驗收 | 竣工驗收、EEWH 送件（如適用）、建案竣工 ESG 成效報告完成、排放邊界更新通知永續發展室 |

### 5.2 延遲處理程序

里程碑狀態標記為「延遲」時，工程室**應**：

1. 在備註欄填入延遲原因
2. 評估對後續里程碑及整體工期之影響
3. 提出修正後的預定完成日
4. 必要時提報工程室主任或 ESG 委員會知悉

### 5.3 排放邊界通知要求

建案涉及以下情況時，工程室**應**於竣工後 30 日內通知永續發展室評估排放邊界影響：

- 新建設施完工納入使用
- 設施拆除或停用
- 重大設備（冷媒系統、發電設備）新增或汰除
