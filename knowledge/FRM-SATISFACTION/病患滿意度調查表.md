# 病患滿意度調查表

**表單編號：** FRM-SATISFACTION
**表單版本：** 1.0
**管理單位：** 社工室
**填報對象：** 就醫病患及家屬

---

## 1. 表單資訊

| 欄位 | 說明 |
|------|------|
| **用途** | 蒐集國軍高雄總醫院病患及家屬對醫療服務之滿意度評估，作為服務品質改善及 ESG 社會面（S3 社區參與）績效衡量指標 |
| **填報頻率** | 常態性收集（門診、住院、出院時）；社區活動時亦可使用本表 |
| **匿名說明** | 本調查可匿名填寫，個人資料不作為評鑑目的，僅用於服務改善 |
| **相關報告** | RPT-COMMUNITY 社區醫療服務報告 |
| **統計週期** | 每季彙整分析，納入每年社區醫療服務報告 |

---

## 2. 填寫說明

| 欄位名稱 | 填寫說明 |
|---------|---------|
| **調查日期\*** | 填寫完成本問卷之日期，格式：YYYY-MM-DD |
| **就醫科別** | 填寫本次主要就醫之科別（如：內科、急診、骨科），可留空 |
| **整體滿意度\*** | 請就整體就醫體驗給予評分（5=非常滿意，1=非常不滿意）|
| **環境清潔\*** | 請就院內環境清潔度評分（5=非常滿意，1=非常不滿意）|
| **人員態度\*** | 請就醫護及行政人員服務態度評分（5=非常滿意，1=非常不滿意）|
| **等候時間\*** | 請就掛號、等候看診及領藥等候時間滿意度評分（5=非常滿意，1=非常不滿意）|
| **其他意見** | 歡迎填寫對本院服務之具體建議或表揚內容 |

## 5. 附件與備註

### 5.1 滿意度指標計算方式

社工室每季彙整問卷結果，計算以下指標：

| 指標 | 計算方式 | 目標值 |
|------|---------|------|
| 整體滿意度平均分 | Σ（整體滿意度分數）/ 有效問卷數 | ≥ 4.0 |
| 滿意及非常滿意比率 | 評分4+5之問卷數 / 有效問卷數 | ≥ 80% |
| 環境清潔平均分 | Σ（環境清潔分數）/ 有效問卷數 | ≥ 4.0 |
| 人員態度平均分 | Σ（人員態度分數）/ 有效問卷數 | ≥ 4.2 |
| 等候時間平均分 | Σ（等候時間分數）/ 有效問卷數 | ≥ 3.5 |

### 5.2 問卷發放管道

| 管道 | 說明 |
|------|------|
| 紙本問卷 | 門診候診區、出院時護理站發放 |
| 數位問卷（QR Code）| 出院通知書、院內螢幕 QR Code |
| 社區活動現場 | 義診、健檢等活動結束時發放 |

### 5.3 結果運用說明

- 每季由社工室彙整統計，提報護理部及醫務主任
- 不滿意（評分≤2）之意見須於2週內完成根本原因分析
- 年度彙整結果納入 RPT-COMMUNITY 社區醫療服務報告
- 重要改善行動納入年度服務品質改善計畫（CQI）

### 5.4 資料保存

- 紙本問卷由社工室保存，保存期限2年
- 統計分析檔案由社工室保存，保存期限5年
- 年度彙整結果隨 RPT-COMMUNITY 永久保存
