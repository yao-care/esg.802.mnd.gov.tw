# 廢棄物處理月報表

**表單編號：** FRM-WASTE-MON
**表單版本：** 1.0
**管理單位：** 環安衛室
**填報單位：** 環安衛室

---

## 1. 表單資訊

| 欄位 | 說明 |
|------|------|
| **用途** | 記錄國軍高雄總醫院每月各類廢棄物清運及處理情況，作為年度廢棄物申報、ESG報告及合規稽核之依據 |
| **填報頻率** | 每月填報，於次月10日前完成 |
| **數據來源** | 廢棄物清除處理三聯式聯單、清潔承攬商簽收紀錄 |
| **相關程序** | PRO-WASTE 醫療廢棄物管理程序書 |
| **相關法規** | STD-WASTE-REG 廢棄物管理法規摘要 |

---

## 2. 填寫說明

| 欄位名稱 | 填寫說明 |
|---------|---------|
| **填報月份** | 填寫本報表所代表之月份，格式：YYYY-MM（例：2026-05）|
| **廢棄物類別** | 從下拉選單選擇廢棄物類別。同一月份若有多次清運或多類廢棄物，每筆紀錄填一列。 |
| **重量(kg)** | 填入本次清運之廢棄物重量（公斤）。依聯單記載數值填入，最多2位小數。 |
| **清運機構** | 填入執行清運作業之合法廢棄物清除機構全名（與許可證相符）。一般廢棄物清運至高雄市環保局者填「高雄市政府環境保護局」。 |
| **聯單編號** | 填入廢棄物清除處理三聯式聯單之編號。一般廢棄物若無聯單可填「無（一般垃圾清運）」。 |
| **處理方式** | 從下拉選單選擇廢棄物最終處理方式。 |

---

## 3. 表單欄位

每月如有多類廢棄物或多次清運，每筆各填一列：

| 欄位名稱 | 類型 | 必填 | 說明/選項 |
|---------|------|------|---------|
| 填報月份* | 文字 | 是 | 格式YYYY-MM，例：2026-05 |
| 廢棄物類別* | 下拉選單 | 是 | 一般事業廢棄物 / 感染性事業廢棄物 / 有害事業廢棄物 |
| 重量(kg)* | 數字 | 是 | 聯單記載重量，最多2位小數 |
| 清運機構* | 文字 | 是 | 合法許可機構全名 |
| 聯單編號* | 文字 | 是 | 三聯式聯單編號；無聯單填「無」並說明 |
| 處理方式* | 下拉選單 | 是 | 焚化 / 滅菌 / 掩埋 / 回收再利用 |

> \* 標記欄位為必填

### 3.1 廢棄物類別與處理方式對應表

| 廢棄物類別 | 合規處理方式 | 禁止方式 |
|---------|------------|---------|
| 一般事業廢棄物 | 掩埋、焚化、回收再利用 | 混入感染性廢棄物 |
| 感染性事業廢棄物 | 高溫滅菌後掩埋/掩埋、焚化 | 未滅菌直接掩埋 |
| 有害事業廢棄物 | 焚化（含毒性）、依特性處理 | 一般掩埋 |

## 5. 附件與備註

### 5.1 必要附件

提交本表單時，請同時確認以下文件已存檔：

| 文件 | 說明 |
|------|------|
| 三聯式聯單（第一聯留存）| 感染性及有害廢棄物每次清運之聯單 |
| 處理結果聯（第三聯）| 清運完成後由處理機構返回 |
| 清潔承攬商簽收紀錄 | 一般廢棄物清運日誌 |

### 5.2 廢棄物法規申報

依廢棄物清理法第11條規定，本院須就達申報門檻之廢棄物定期向環境部申報。環安衛室應確認：

- 每年1月確認前一年度廢棄物總量是否達申報門檻
- 如需申報，依環境部規定期限完成網路申報
- 申報紀錄保存5年

### 5.3 數據保存

- 本表單電子檔由環安衛室保存，紙本由環安衛室存檔，保存期限5年
- 三聯式聯單（紙本）保存期限5年，作為廢棄物清除處理之法定紀錄

### 5.4 年度廢棄物減量目標

| 指標 | 基準值 | 目標 | 追蹤方式 |
|------|------|------|---------|
| 感染性廢棄物月均清運量 | 待建立基準 | 逐年維持或降低 | 本表單月報彙整 |
| 有害廢棄物月均清運量 | 待建立基準 | 逐年維持或降低 | 本表單月報彙整 |
| 一般廢棄物資源回收率 | 待建立基準 | 逐年提升 | 清潔承攬商統計 |
