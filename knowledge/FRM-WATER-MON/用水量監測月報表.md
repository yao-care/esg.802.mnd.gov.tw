# 用水量監測月報表

**表單編號：** FRM-WATER-MON
**表單版本：** 1.0
**管理單位：** 工程室
**填報單位：** 工程室

---

## 1. 表單資訊

| 欄位 | 說明 |
|------|------|
| **用途** | 記錄國軍高雄總醫院每月用水量，追蹤節水績效，供年度ESG報告及水資源管理程序書執行成效評估使用 |
| **填報頻率** | 每月填報，於次月15日前提交永續發展室 |
| **數據來源** | 自來水水表月底讀數；自來水帳單 |
| **相關程序** | PRO-WATER 水資源管理程序書 |

---

## 2. 填寫說明

| 欄位名稱 | 填寫說明 |
|---------|---------|
| **填報月份** | 填寫本報表所代表之月份，格式：YYYY-MM（例：2026-05）|
| **水表讀數(m³)** | 填入月底（最後一個工作日）自來水主水表讀數（立方公尺）。若院區有多支計費水表，填入合計讀數或分別記錄後加總。|
| **當月用水量(m³)** | 計算當月實際用水量：當月用水量 = 本月水表讀數 - 上月水表讀數。亦可直接填入自來水帳單計費用水量。|
| **上月用水量(m³)** | 填入上一個月份之用水量，供環比分析。 |
| **去年同月用水量(m³)** | 填入去年同一月份之用水量，供年比分析。 |
| **備註** | 若本月用水量與上月或去年同月相比差異超過5%，須說明原因（如：冷卻水塔換水、施工用水、管線維修後補水、天氣炎熱空調加重等）。|

---

## 3. 表單欄位

| 欄位名稱 | 類型 | 必填 | 說明 |
|---------|------|------|------|
| 填報月份* | 文字 | 是 | 格式YYYY-MM，例：2026-05 |
| 水表讀數(m³)* | 數字 | 是 | 月底自來水主水表累計讀數 |
| 當月用水量(m³)* | 數字 | 是 | 本月水表讀數 - 上月水表讀數 |
| 上月用水量(m³) | 數字 | 否 | 上月用水量，供環比 |
| 去年同月用水量(m³) | 數字 | 否 | 去年同月用水量，供年比 |
| 備註 | 文字區塊 | 否 | 差異超過5%時說明原因 |

> \* 標記欄位為必填

### 3.1 比較分析欄位（填報人自行計算）

| 比較項目 | 計算公式 | 警示門檻 |
|---------|---------|---------|
| 與上月環比增減 | (本月用水 - 上月用水) ÷ 上月用水 × 100% | 差異 > ±5% 須說明 |
| 與去年同月年比增減 | (本月用水 - 去年同月) ÷ 去年同月 × 100% | 差異 > ±5% 須說明 |

## 5. 附件與備註

### 5.1 必要附件

提交本表單時，請確認以下資料已存檔：

| 文件 | 說明 |
|------|------|
| 自來水帳單（當月）| 作為用水量原始憑證，掃描存檔 |

### 5.2 用水量計算說明

若院區有多支計費水表（主表 + 分表），依以下原則彙整：

```
當月院區總用水量（m³）= Σ 各計費水表當月用水量
                    - 非本院計費之排除量（如有）
```

若部分用水為非本院承擔費用（如承租單位自行繳費），應在備註欄說明。

### 5.3 年度用水彙整

本表單每月數據由永續發展室彙整為年度報表，納入 ESG 報告水資源章節：

| 指標 | 說明 |
|------|------|
| 年度取水量（m³）| 全年12個月用水量加總 |
| 每床日用水量 | 年度用水量 ÷ 年度住院床日數 |
| 相較基準年增減率 | 以首年為基準年計算 |

### 5.4 數據保存

- 本表單由工程室存檔，保存期限5年
- 自來水帳單（紙本）由工程室保管，保存期限5年
- 作為年度ESG報告水資源數據佐證文件
