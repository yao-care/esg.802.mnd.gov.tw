# 溫室氣體排放量計算方法指引

**適用機構：** 國軍高雄總醫院
**標準依據：** ISO 14064-1:2018；IPCC AR6（2021）；環境部113年2月5日公告溫室氣體排放係數
**最後更新：** 2026-03-19

---

## 1. 通用計算公式

### 1.1 基本公式

溫室氣體排放量計算採以下通用公式：

```
排放量（tCO2e）= 活動數據 × 排放係數 × GWP
```

各參數說明：

| 參數 | 說明 | 單位 |
|------|------|------|
| 活動數據 | 燃料消耗量、冷媒補充量、用電度數等 | 依排放源各異（公升、公斤、度等） |
| 排放係數 | 單位活動量產生之溫室氣體質量 | tGHG/活動量單位 |
| GWP | 全球暖化潛勢（Global Warming Potential） | tCO2e/tGHG |
| 排放量 | 以CO2當量表示之溫室氣體排放量 | tCO2e |

### 1.2 多種溫室氣體累計公式

當同一活動同時產生多種溫室氣體（如燃料燃燒產生CO2、CH4、N2O）時：

```
排放量（tCO2e）= 活動數據 × Σ（各溫室氣體排放係數 × 各溫室氣體GWP）
              = 活動數據 × (CO2排放係數×GWP_CO2 + CH4排放係數×GWP_CH4 + N2O排放係數×GWP_N2O)
```

## 2. 各排放源計算公式

### 2.1 固定源燃料燃燒

#### 2.1.1 天然氣（廚房瓦斯爐）

```
天然氣排放量（tCO2e）= 天然氣用量(m³) × 熱值(Kcal/m³) ÷ 1,000,000
                    × [CO2排放係數(tCO2/TJ) × GWP_CO2(1)
                    + CH4排放係數(tCH4/TJ) × GWP_CH4(27.9)
                    + N2O排放係數(tN2O/TJ) × GWP_N2O(273)]
```

簡化公式（使用環境部公告之每立方公尺排放係數）：

```
天然氣排放量（tCO2e）= 天然氣用量(m³)
                    × (CO2排放係數_NG2 × 1 + CH4排放係數_NG2 × 27.9 + N2O排放係數_NG2 × 273)
```

其中排放係數（每立方公尺）：
- CO2：2.0500281014 tCO2/千m³
- CH4：0.0000365424 tCH4/m³
- N2O：0.0000036542 tN2O/m³

**天然氣度數認定方式：** 欣高石油氣公司帳單統計週期（上月25日至當月25日），跨年份度數依天數比例拆分。

#### 2.1.2 液化石油氣（廚房瓦斯爐）

```
LPG排放量（tCO2e）= LPG用量(kg)
                 × (CO2排放係數_LPG × 1 + CH4排放係數_LPG × 27.9 + N2O排放係數_LPG × 273)
```

其中排放係數（每公斤）：
- CO2：2.8986606418 tCO2/t
- CH4：0.0000459376 tCH4/kg
- N2O：0.0000045938 tN2O/kg

#### 2.1.3 柴油（緊急發電機，固定源）

```
柴油（固定源）排放量（tCO2e）= 柴油用量(公秉=kL)
                            × (CO2排放係數_固定柴油 × 1 + CH4排放係數 × 27.9 + N2O排放係數 × 273)
```

其中排放係數（每公秉）：
- CO2：2.6792488757 tCO2/kL
- CH4：0.0001084716 tCH4/kL
- N2O：0.0000216943 tN2O/kL

### 2.2 移動源燃料燃燒

#### 2.2.1 車用汽油（公務車）

```
車用汽油排放量（tCO2e）= 車用汽油用量(公秉=kL)
                      × (CO2排放係數_移動汽油 × 1 + CH4排放係數_移動汽油-氧化觸媒 × 27.9
                         + N2O排放係數_移動汽油-氧化觸媒 × 273)
```

其中排放係數（每公秉，移動源-氧化觸媒車輛）：
- CO2：2.2010417906 tCO2/kL
- CH4：0.0007940266 tCH4/kL
- N2O：0.0002540885 tN2O/kL

#### 2.2.2 車用柴油（公務車）

```
車用柴油排放量（tCO2e）= 車用柴油用量(公秉=kL)
                      × (CO2排放係數_移動柴油 × 1 + CH4排放係數_移動柴油 × 27.9
                         + N2O排放係數_移動柴油 × 273)
```

其中排放係數（每公秉，移動源）：
- CO2：2.6792488757 tCO2/kL
- CH4：0.0001410131 tCH4/kL
- N2O：0.0001410131 tN2O/kL

### 2.3 逸散源計算

#### 2.3.1 車用尿素水解

反應式：CO(NH₂)₂ + H₂O → 2NH₃ + CO₂

```
尿素水解排放量（tCO2e）= 車用尿素購買量(公升) × 尿素溶液比重(1.09 kg/L)
                      × 尿素濃度(32.5%) ÷ 尿素分子量(60 g/mol)
                      × CO2分子量(44 g/mol) ÷ 1,000,000 × GWP_CO2(1)
```

參數說明：
- 尿素濃度取SDS中31.8%~33.2%的中間值32.5%
- 比重依SDS記錄1.09 kg/L
- 假設溶液中尿素成分後續皆以水解反應完全逸散

#### 2.3.2 冷媒設施逸散

```
冷媒排放量（tCO2e）= 冷媒補充量(kg) × GWP(冷媒種類) ÷ 1,000
```

計算說明：
- 新購設備：計入設備原始冷媒填充量
- 既有設備維修：計入維修時實際冷媒補充量
- 若維修紀錄無法確認實際補充量：採計該設備原始填充量（銘牌資訊）

#### 2.3.3 麻醉氣體逸散

```
麻醉氣體排放量（tCO2e）= 麻醉藥品請領量(kg) × GWP(藥品種類) ÷ 1,000
```

Sevoflurane比重換算：
- 仿單說明比重1.520~1.525，統一採最大值1.525
- 用量單位若為毫升(mL)：換算為 kg = mL × 1.525 ÷ 1,000

數據涵蓋期間：藥衛材管理系統登錄時間，實際涵蓋2024年12月24日至2025年12月22日。

#### 2.3.4 氣體鋼瓶逸散

```
氣體鋼瓶排放量（tCO2e）= 鋼瓶購買量(支) × CO2填充量(kg/支) × GWP_CO2(1) ÷ 1,000
```

注意：混合氣體鋼瓶（如BH03混合氣CO2+H2+N2）僅計算CO2成分之填充量。

#### 2.3.5 消防設備逸散

```
消防設備排放量（tCO2e）= 設備購買量(支) × 溫室氣體填充量(kg/支) × GWP ÷ 1,000
```

#### 2.3.6 GCB瓦斯斷路器逸散

```
GCB逸散排放量（tCO2e）= SF6補充量(kg) × GWP_SF6(25,200) ÷ 1,000
```

#### 2.3.7 噴罐逸散

```
噴罐排放量（tCO2e）= 噴罐購買量(支) × 推進劑填充量(kg/支) × GWP_CO2(1) ÷ 1,000
```

### 2.4 類別2 外購電力

```
電力排放量（tCO2e）= 總用電度數(kWh) × 電力排碳係數(kgCO2e/度) ÷ 1,000
```

計算說明：
- 總用電度數 = Σ各電號用電度數 - 租用單位排除量 - 721營站排除量
- 電力排碳係數採用經濟部能源署公告之前一年度係數（例：2025年盤查使用2024年係數0.4740 kgCO2e/度）
- 電費單統計週期若跨年份，依天數比例拆分

## 6. 計算範例

### 6.1 天然氣計算範例（2025年）

```
天然氣用量 = 13,024.8388 m³
低位熱值 = 8,728 Kcal/m³（環境部114年公告NG2）

CO2排放量 = 13,024.8388 × 2.0500281014 ÷ 1,000 = 26.7012 tCO2
CH4排放量 = 13,024.8388 × 0.0000365424 × 27.9 ÷ 1,000 = 0.0133 tCO2e
N2O排放量 = 13,024.8388 × 0.0000036542 × 273 ÷ 1,000 = 0.0130 tCO2e
天然氣合計 = 26.7275 ≈ 26.7276 tCO2e
```

### 6.2 冷媒計算範例（R-134a大樓冰水主機，2025年）

```
R-134a填充量 = 600 kg（新購冰水主機KLTW-400D-3DLJ2）
GWP_R-134a = 1,530

冷媒排放量 = 600 × 1,530 ÷ 1,000 = 918.0 tCO2e
```

### 6.3 Sevoflurane計算範例（2025年）

```
Sevoflurane購買量 = 86,000 mL
Sevoflurane比重 = 1.525 g/mL（仿單最大值）
換算為kg = 86,000 × 1.525 ÷ 1,000 = 131.15 kg
GWP_Sevoflurane = 144

Sevoflurane排放量 = 131.15 × 144 ÷ 1,000 = 18.8856 tCO2e
```

### 6.4 車用尿素計算範例（2025年）

```
車用尿素購買量 = 20 公升
尿素溶液比重 = 1.09 kg/L
尿素濃度 = 32.5%（SDS中間值）
尿素分子量 = 60 g/mol
CO2分子量 = 44 g/mol

CO2逸散量(kg) = 20 × 1.09 × 0.325 ÷ 60 × 44 = 5.2146 kg
排放量（tCO2e）= 5.2146 ÷ 1,000 × 1 = 0.0052 tCO2e
```

### 6.5 外購電力計算範例（2025年）

```
總台電用電度數（4電號合計）= 15,691,527.7081 度（含需排除量）
排除電量（租用單位 + 721營站）= 596,999.0000 度
本院淨用電度數 = 15,691,527.7081 - 596,999.0000 = 15,094,528.7081 度

電力排放量 = 15,094,528.7081 × 0.4740 ÷ 1,000 = 7,154.8066 tCO2e
```

## 7. 數據品質管理要點

### 7.1 排放係數選用優先順序

1. 國家排放係數（環境部公告）
2. 國際公告或IPCC公告適用係數
3. 國內外相關文獻排放係數

### 7.2 係數更新時機

| 係數類型 | 更新頻率 | 更新來源 |
|---------|---------|---------|
| 燃料燃燒排放係數 | 依環境部公告更新 | 環境部溫室氣體排放係數管理表 |
| 燃料熱值 | 年度更新 | 環境部年度公告 |
| 電力排碳係數 | 年度更新（滯後一年）| 經濟部能源署公告 |
| GWP值 | 依IPCC報告更新 | IPCC AR版本（目前AR6） |
| 麻醉氣體GWP | 依ASA文獻更新 | ASA官方文獻 |

### 7.3 不確定性說明

| 排放源 | 活動數據不確定性 | 排放係數不確定性 |
|--------|--------------|--------------|
| 天然氣（連續量測）| ±1%（標檢局規範）| ±21%（IPCC建議） |
| 外購電力（連續量測）| ±1%（CNMV 46規範）| ±7%（IPCC 1996）|
| 冷媒（補充量法）| 中度（受設備實際狀況影響）| 低（直接採用GWP值） |
