# 設備能源效率指引

**適用機構：** 國軍高雄總醫院
**制定單位：** 工程室
**版本：** 1.0
**生效日期：** 2026-05-05

---

## 1. 目的

本指引提供設備選購與汰換時的能源效率判斷標準，確保採購人員、工程師及相關決策者能依據客觀技術指標選用高效率設備，支持 PLN-ENERGY 節能減碳行動計畫的執行。

適用設備類別：

- 照明設備（室內燈具、戶外燈具）
- 空調設備（分離式冷氣、冰水主機）
- 電動機（馬達）

---

## 2. 背景知識

### 2.1 醫院用電結構

依據 RPT-GHG-2025，本院2025年淨用電量為 15,094,528 度，電力排放量佔總排放約83%。醫院主要耗電設備依序為：空調系統、照明系統、醫療設備、其他用電。

照明與空調系統通常佔醫院總用電的 40%~60%，亦是節能改善效益最高的領域。

### 2.2 能效標準體系

台灣主要能效法規與標準：

| 標準/制度 | 主管機關 | 適用設備 |
|---------|---------|---------|
| 能源效率分級（能效標示）| 經濟部能源署 | 冷氣、冰箱、洗衣機等 |
| CNS 能效標準 | 經濟部標準檢驗局（BSMI）| 各類電器 |
| 綠建築評估手冊（EEWH）| 內政部建築研究所 | 建築用電設備 |
| 台灣電氣法規（屋內線路裝置規則）| 經濟部 | 電力系統 |

### 2.3 效率指標說明

| 指標 | 全名 | 適用設備 | 越高越好/越低越好 |
|------|------|---------|---------------|
| lm/W | 流明/瓦（發光效率）| 照明 | 越高越好 |
| CSPF | 冷季性能係數（Cooling Seasonal Performance Factor）| 分離式冷氣 | 越高越好 |
| COP | 性能係數（Coefficient of Performance）| 冰水主機 | 越高越好 |
| EER | 能量效率比（Energy Efficiency Ratio）| 冷氣 | 越高越好 |
| IE 等級 | 國際馬達效率等級（IE1~IE4）| 電動機 | 等級越高越好 |

## 3. 方法與選購標準

### 3.1 照明設備

#### 3.1.1 發光效率（lm/W）標準

選購室內照明燈具時，應符合以下最低發光效率要求：

| 燈具類型 | 最低要求（lm/W）| 建議規格（lm/W）| 備注 |
|---------|--------------|--------------|------|
| LED 直管燈（T8替換型）| ≥ 100 | ≥ 130 | 取代傳統T8日光燈管 |
| LED 崁燈（CNS 15-20W）| ≥ 90 | ≥ 110 | 門診走廊、病房通用 |
| LED 平板燈（2×4呎）| ≥ 100 | ≥ 120 | 辦公室、會議室 |
| LED 投光燈（戶外）| ≥ 100 | ≥ 130 | 停車場、廣場 |
| LED 路燈（院區道路）| ≥ 110 | ≥ 140 | 道路照明 |

> 參考依據：CNS 15630（LED燈—性能要求）、經濟部能源署節能燈具認證標準

#### 3.1.2 照明功率密度（LPD）

依 EEWH 綠建築評估手冊規定，醫院空間照明功率密度上限：

| 空間類型 | LPD上限（W/m²）|
|---------|-------------|
| 一般走廊 | 5 |
| 行政辦公室 | 10 |
| 門診診間 | 10 |
| 病房 | 8 |
| 手術室 | 另有專業照度規範 |

#### 3.1.3 選購核對清單

選購照明設備時確認以下項目：

- [ ] 具備 CNS 驗證或 BSMI 電子電器商品型式認可
- [ ] 發光效率符合上表最低要求
- [ ] 演色指數（CRI）≥ 80（病房、診間 ≥ 90）
- [ ] 色溫符合使用環境（辦公/走廊 4000K~5000K；病房 3000K~4000K）
- [ ] 保固期 ≥ 3年

---

### 3.2 空調設備

#### 3.2.1 分離式冷氣機：CSPF標準

依經濟部能源署能源效率分級標示規定：

| 能效等級 | CSPF（W/W）| 採購建議 |
|---------|----------|---------|
| 1級（最高效）| ≥ 5.85 | 強烈建議採購 |
| 2級 | 5.30~5.84 | 建議採購 |
| 3級 | 4.80~5.29 | 可接受（低使用頻率場所）|
| 4級 | 4.30~4.79 | 不建議新購 |
| 5級（最低效）| < 4.30 | 禁止採購 |

> 本院採購原則：一般病房及辦公室空調**至少達2級（CSPF ≥ 5.30）**；高負載區域（急診、加護病房）建議採購1級。

#### 3.2.2 冰水主機：COP標準

| 設備類型 | 最低 COP | 建議 COP | 備注 |
|---------|---------|---------|------|
| 離心式冰水主機 | ≥ 5.0 | ≥ 6.0 | AHRI 550/590標準 |
| 螺旋式冰水主機 | ≥ 4.5 | ≥ 5.5 | 中小型容量 |
| 渦卷式冰水主機 | ≥ 4.0 | ≥ 4.8 | 小型系統 |

> 本院現有冰水主機 KLTW-400D-3DLJ2 採用 R-134a 冷媒，汰換時應同時評估改採低 GWP 冷媒（如 R-1234ze）之可行性。

#### 3.2.3 選購核對清單

- [ ] 能效等級符合上表最低要求
- [ ] 具備 BSMI 型式認可
- [ ] 冷媒種類符合蒙特婁議定書最新修正（禁用 R-22）
- [ ] 附廠商能效試驗報告（第三方驗測）
- [ ] 具備遠端監控或 BMS 介面（大型主機）

---

### 3.3 電動機（馬達）

#### 3.3.1 IE 效率等級標準

依 IEC 60034-30-1 國際標準：

| IE 等級 | 說明 | 適用場合 |
|---------|------|---------|
| IE1（標準效率）| 基準值 | 不建議採購 |
| IE2（高效率）| 比 IE1 節能 2~8% | 低負載、短時使用 |
| IE3（超高效率）| 比 IE1 節能 4~15% | 本院一般採購最低標準 |
| IE4（超超高效率）| 比 IE1 節能 7~20% | 高負載、長時連續運轉 |

> **本院採購政策：** 所有新購及汰換電動機（≥ 0.75 kW）一律採用 **IE3 以上**等級。

#### 3.3.2 變頻驅動器（VFD）

抽水馬達、送排風機建議搭配變頻驅動器（VFD/Inverter），依負載需求調整轉速：

| 設備類型 | 節能效益估算 | 備注 |
|---------|------------|------|
| 冷卻水泵 | 20~40% | 依冰水主機負載連動 |
| 空調送風機 | 15~30% | 依 CO₂ 濃度或溫度回饋控制 |
| 排氣風機 | 10~25% | 依換氣次數需求調整 |

## 4. 範例

### 4.1 照明汰換效益計算範例

**案例：** 走廊50支T8日光燈管（36W/支）汰換為LED直管（18W/支），每日點燈12小時

```
原有耗電：50 × 36W × 12h = 21,600 Wh/日 = 21.6 度/日
汰換後：50 × 18W × 12h = 10,800 Wh/日 = 10.8 度/日
每日節電：10.8 度
年節電量：10.8 × 365 = 3,942 度/年
年減碳量：3,942 × 0.4740 ÷ 1,000 = 1.87 tCO2e/年
```

### 4.2 冷氣汰換效益計算範例

**案例：** 1台舊型窗型冷氣（1HP，EER=2.5）汰換為變頻分離式冷氣（1HP，CSPF=5.5）

```
舊機每小時耗電：0.735kW ÷ 2.5 = 0.294 kW
新機每小時耗電：0.735kW ÷ 5.5 = 0.134 kW
每小時節電：0.160 kW
年節電量（假設運轉2,000小時）：0.160 × 2,000 = 320 度/年
年減碳量：320 × 0.4740 ÷ 1,000 = 0.15 tCO2e/年
```

### 4.3 馬達汰換效益計算範例

**案例：** 1台IE2馬達（15kW，η=91.0%）汰換為IE3馬達（15kW，η=92.6%）

```
IE2每小時耗電：15 ÷ 0.910 = 16.48 kW
IE3每小時耗電：15 ÷ 0.926 = 16.20 kW
每小時節電：0.28 kW
年節電量（假設連續運轉6,000小時）：0.28 × 6,000 = 1,680 度/年
年減碳量：1,680 × 0.4740 ÷ 1,000 = 0.80 tCO2e/年
```
