# 綠建築設計指引

**制定單位：** 工程室
**版本：** 1.0
**生效日期：** 2026-05-05

---

## 1. 目的與參考依據

### 1.1 目的

本指引旨在提供國軍高雄總醫院新建、改建工程適用之綠建築設計準則，協助工程室及設計單位於規劃設計階段落實台灣 EEWH 綠建築標章要求，達成節能減碳、改善室內環境品質及減少建築對環境衝擊之目標。

### 1.2 適用範圍

本指引適用於本院建築面積超過 500 平方公尺之新建工程，以及主要機電或建築系統改建工程。較小規模工程得參考本指引精神辦理，不強制申請標章。

### 1.3 參考依據

| 依據 | 說明 |
|------|------|
| 內政部建築研究所《綠建築評估手冊》 | EEWH 九大指標評估基準（最新版） |
| 建築技術規則《建築節能設計規範》 | 法定建築能源效率要求 |
| 環保署《醫療院所節能減碳指引》 | 醫療設施特殊能耗管理建議 |
| PLN-CONSTRUCTION | 建案 ESG 規劃書 |

## 2. EEWH 綠建築標章認證等級

台灣 EEWH（Ecology, Energy Saving, Waste Reduction, Health）綠建築標章分為五個等級：

| 等級 | 說明 | 取得門檻概述 |
|------|------|------------|
| **合格級** | 基本符合綠建築要求 | 達到最低指標分數，通過必要指標 |
| **銅級** | 良好綠建築 | 高於合格級標準，多項指標表現良好 |
| **銀級** | 優良綠建築 | 多項指標達優良水準 |
| **金級** | 卓越綠建築 | 大多數指標表現優異 |
| **鑽石級** | 最高等級綠建築 | 全面卓越，為台灣最優建築環境績效 |

**本院建議目標：** 新建工程至少取得**銀級**；整修工程至少達**銅級**水準。

## 3. EEWH 九大指標與醫院適用說明

### 3.1 九大指標說明

| 指標 | 名稱 | 醫院建設重點說明 |
|------|------|--------------|
| 1 | **生物多樣性** | 院區綠地規劃應盡量保留原生植栽，設置生態池或雨水花園 |
| 2 | **綠化量** | 屋頂、露台及院區公共空間植栽綠化；綠覆率建議 ≥ 15% |
| 3 | **基地保水** | 透水鋪面（停車場、步道）；雨水截流及回收利用（澆灌）|
| 4 | **日常節能** | 最重要指標之一；詳見第 4 節能源效能要求 |
| 5 | **二氧化碳減量** | 輕量化結構設計；優先選用低碳建材（如鋼構替代傳統 RC）|
| 6 | **廢棄物減量** | 施工廢棄物分類管理；選用再生建材；減少裝修浪費 |
| 7 | **室內環境** | 最關鍵醫院指標；詳見第 5 節室內空氣品質要求 |
| 8 | **水資源** | 節水設備選用；雨水再利用；廢水回收（中水系統）|
| 9 | **污水垃圾改善** | 醫療廢水處理符合排放標準；垃圾動線分離規劃 |

### 3.2 醫院必要指標優先順序

醫院建築特殊性，本指引特別強調以下指標為優先：

1. **日常節能（指標4）**：外購電力佔本院排放 83%，節能效益最大
2. **室內環境（指標7）**：攸關病患、醫護及訪客健康
3. **水資源（指標8）**：醫療耗水量大，節水有助降低運營成本
4. **廢棄物減量（指標6）**：施工及醫療廢棄物管理

## 4. 能源效能要求（醫院適用）

### 4.1 外殼節能

| 構件 | 要求 |
|------|------|
| 外牆隔熱 | 外牆平均熱傳透率 U 值 ≤ 3.5 W/m²K（依建築技術規則）|
| 屋頂隔熱 | 屋頂平均熱傳透率 U 值 ≤ 1.0 W/m²K |
| 開窗設計 | 窗牆比（WWR）控制於 20-40%；採用複層玻璃或低輻射 Low-E 玻璃 |

### 4.2 空調系統

| 項目 | 要求 |
|------|------|
| 冰水主機 COP | ≥ 5.0（中央空調系統）|
| 分離式冷氣 | 選用能效標示一級產品 |
| 變頻控制 | 冰水泵、空調箱送風機採變頻驅動 |
| 分區控制 | 依使用時段及功能分區獨立控制 |

### 4.3 照明系統

| 區域 | 要求 |
|------|------|
| 所有照明 | 全面採用 LED 燈具（光效 ≥ 100 lm/W）|
| 公共走廊 | 加裝人體感應控制，離峰時段自動調低至 30% |
| 手術室 / ICU | 專用手術燈符合醫療照度標準（≥ 10,000 lux）|
| 戶外照明 | 採用 LED 投光燈，具有光害防制設計 |

## 5. 室內空氣品質（醫院適用）

### 5.1 通風要求

| 區域類型 | 換氣次數要求 | 備註 |
|---------|-----------|------|
| 手術室 | ≥ 20 次/小時（正壓）| 需 HEPA 過濾（≥ 99.97%）|
| 加護病房（ICU） | ≥ 6 次新鮮外氣 / 小時 | 建議正壓設計 |
| 隔離病房 | ≥ 6 次/小時（負壓）| 獨立排氣，不循環 |
| 一般病房 | ≥ 2 次新鮮外氣 / 小時 | |
| 門診診間 | ≥ 4 次/小時 | 建議 CO₂ 偵測器 |
| 行政辦公區 | ≥ 2 次新鮮外氣 / 小時 | |

### 5.2 建材 VOC 限制

| 建材類型 | 揮發性有機化合物（VOC）要求 |
|---------|------------------------|
| 油漆、塗料 | ≤ 50 g/L（水性漆）|
| 地板黏著劑 | ≤ 50 g/L |
| 木作板材 | E0 或 E1 甲醛逸散等級 |
| 地毯 | 不建議用於醫療區域 |

### 5.3 噪音控制

| 空間 | 室內噪音上限 |
|------|-----------|
| 手術室、ICU | ≤ 35 dBA |
| 一般病房 | ≤ 40 dBA（夜間）|
| 門診診間 | ≤ 45 dBA |
| 行政辦公 | ≤ 50 dBA |

## 6. 綠建築申請流程（EEWH）

| 階段 | 工作項目 | 辦理時機 |
|------|---------|---------|
| 規劃設計 | 確認是否達到申請門檻；選定目標等級；委託綠建築顧問評估 | 設計初期 |
| 設計完成 | 提送設計書件至內政部建築研究所申請候選綠建築證書 | 設計定案後 |
| 施工期間 | 依候選證書要求施工；保留施工紀錄 | 施工全程 |
| 竣工 | 申請綠建築標章；現場勘驗 | 竣工後 3 個月內 |
| 標章維護 | 定期更新（標章效期 3 年）| 標章到期前 6 個月 |
