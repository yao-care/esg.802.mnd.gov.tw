# 利害關係人鑑別矩陣

**適用機構：** 國軍高雄總醫院
**鑑別基準：** GRI 準則 / TCFD 建議
**最後更新：** 2026-05-05

---

## 1. 矩陣目的與方法

### 1.1 目的

本矩陣依據 GRI 準則重大性鑑別原則及 TCFD 利害關係人參與建議，系統性辨識國軍高雄總醫院各類利害關係人，評估其對 ESG 議題的影響程度與關注程度，作為制定溝通策略及回應機制的依據，並供 ESG 委員會（PRO-ESG-COMMITTEE）審議使用。

### 1.2 鑑別方法

**步驟1：**辨識可能受本院活動影響，或可能對本院活動產生影響的群體。

**步驟2：**依以下兩個維度進行評分：
- **影響程度**：利害關係人對本院 ESG 績效的影響力（高/中/低）
- **關注程度**：利害關係人對本院 ESG 議題的關注強度（高/中/低）

**步驟3：**依優先矩陣分類，決定溝通頻率與回應機制深度。

## 3. 優先矩陣評分標準

### 3.1 影響程度定義

| 等級 | 定義 |
|------|------|
| **高** | 對本院 ESG 政策、目標或資源配置有直接決定性影響；或違規將導致重大法律/財務後果 |
| **中** | 對本院 ESG 執行方向有實質影響；或對本院聲譽有顯著影響 |
| **低** | 影響範圍有限；或間接影響，需累積才顯著 |

### 3.2 關注程度定義

| 等級 | 定義 |
|------|------|
| **高** | 積極主動關注本院 ESG 績效，會主動蒐集資訊或提出要求 |
| **中** | 有一定關注，但通常被動接收資訊；特定情況下會提出意見 |
| **低** | 關注程度低，僅在直接相關時才有反應 |

### 3.3 優先等級矩陣

| | 關注程度高 | 關注程度中 | 關注程度低 |
|--|-----------|-----------|-----------|
| **影響程度高** | 第一優先 | 第一優先 | 第二優先 |
| **影響程度中** | 第一優先 | 第二優先 | 第三優先 |
| **影響程度低** | 第二優先 | 第三優先 | 第三優先 |
