# 職業安全衛生委員會會議紀錄

**制定單位：** 環安衛室
**版本：** 1.0
**生效日期：** 2026-05-05

---

## 1. 紀錄目的

本登記冊記錄國軍高雄總醫院職業安全衛生委員會（以下簡稱「委員會」）各次定期會議及臨時會議之議程、決議及追蹤事項，以符合《職業安全衛生法》第23條關於勞工安全衛生組織設置及定期開會之法定要求，並作為年度職安衛績效審查之主要佐證文件。

**追蹤資訊說明：**

- 委員會組成、會議召開頻率及法定義務
- 每次會議之出席成員、討論議題及決議事項
- 決議事項之執行狀態追蹤

---

## 2. 紀錄格式（欄位定義）

### 2.1 會議基本資料欄位

| 欄位名稱 | 說明 | 型別 | 必填 |
|---------|------|------|------|
| 會議流水號 | 格式：OHS-YYYY-QQ（如 OHS-2026-Q1）| 文字 | 是 |
| 會議日期 | 召開日期，格式：YYYY-MM-DD | 日期 | 是 |
| 會議類型 | 定期會議 / 臨時會議 | 選項 | 是 |
| 主持人 | 主任委員姓名及職稱 | 文字 | 是 |
| 出席人員 | 出席委員清單（姓名、職稱）| 文字 | 是 |
| 出席率 | 出席委員數/委員總數 | 數值 | 是 |
| 紀錄人 | 擔任會議紀錄之環安衛室人員姓名 | 文字 | 是 |

### 2.2 議題與決議欄位

| 欄位名稱 | 說明 | 型別 | 必填 |
|---------|------|------|------|
| 議題編號 | 格式：OHS-YYYY-QQ-A01（A=議題）| 文字 | 是 |
| 議題類別 | 年度計畫 / 危害改善 / 事件追蹤 / 法規更新 / 其他 | 選項 | 是 |
| 議題說明 | 議題內容摘要 | 文字 | 是 |
| 決議內容 | 委員會決議之行動方案 | 文字 | 是 |
| 執行單位 | 負責執行決議之科室或職稱 | 文字 | 是 |

| 執行狀態 | 待辦 / 進行中 / 已完成 / 展延 | 選項 | 是 |
| 追蹤說明 | 執行進度說明或展延原因 | 文字 | 否 |

## 3. 更新頻率與責任人

### 3.1 定期會議召開規定

依《職業安全衛生法》第23條，本院職業安全衛生委員會每季召開至少一次：

| 季別 | 召開月份 | 截止日期 |
|------|---------|---------|
| 第一季（Q1）| 1月或3月 | 3月31日前 |
| 第二季（Q2）| 4月或6月 | 6月30日前 |
| 第三季（Q3）| 7月或9月 | 9月30日前 |
| 第四季（Q4）| 10月或12月 | 12月31日前 |

> 如遇重大職業災害或緊急事件，得召開臨時會議，不計入季度配額。

### 3.2 紀錄更新責任

| 作業項目 | 責任人 | 時效 |
|---------|------|------|
| 會議紀錄初稿 | 環安衛室（秘書）| 會議後3個工作日內 |
| 委員確認與簽名 | 所有與會委員 | 會議後5個工作日內 |
| 紀錄歸檔至本登記冊 | 環安衛室 | 委員確認後立即 |
| 決議追蹤更新 | 環安衛室 | 每次委員會召開前更新 |
| 本年度紀錄彙整 | 環安衛室 | 每年12月31日前 |

### 3.3 委員會組成架構

本院職業安全衛生委員會依職安法規定組成如下：

| 職位 | 擔任人員 | 備注 |
|------|---------|------|
| 主任委員 | 院長或副院長 | 法定主持人 |
| 副主任委員 | 主管職安衛業務之主管（環安衛室主任）| 代理主任委員職務 |
| 委員（管理代表）| 醫務主任、護理部主任、行政組組長 | 各部門最高主管代表 |
| 委員（各單位代表）| 工程室主任、感染管制師、急診主任等 | 視組織規模調整 |
| 職業安全衛生人員 | 環安衛室職安人員（含職業安全管理師）| 至少1名，法定必置 |
| 勞工代表 | 由員工互選產生 | 佔委員會人數 1/3 以上 |
| 秘書 | 環安衛室指定人員 | 負責會議召集、紀錄及追蹤 |
