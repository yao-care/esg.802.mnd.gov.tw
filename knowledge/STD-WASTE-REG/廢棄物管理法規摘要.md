# 廢棄物管理法規摘要

## 2. 適用條款

### 2.1 廢棄物清理法（主要條款）

| 條號 | 條文重點 | 適用情境 |
|------|---------|---------|
| 第2條 | 廢棄物定義與分類（一般廢棄物、事業廢棄物）| 廢棄物分類基礎 |
| 第11條 | 事業廢棄物產生者的申報義務 | 年度廢棄物申報 |
| 第28條 | 事業廢棄物清除、處理須委託合法許可機構 | 委外清運資格查核 |
| 第30條 | 事業廢棄物清理計畫書 | 超過申報門檻之機構須提交 |
| 第36條 | 廢棄物清除處理聯單（三聯式）規定 | 聯單管理 |
| 第51條 | 違規罰則（非法清除、處理）| 合規重要性依據 |
| 第71條 | 廢棄物棄置罰則 | 禁止隨意棄置 |

### 2.2 事業廢棄物貯存清除處理方法及設施標準

| 條號/規定 | 條文重點 | 本院對應措施 |
|---------|---------|------------|
| 第3條 | 事業廢棄物貯存須防止污染環境及危害人體健康 | 暫存場所設施要求 |
| 第4條 | 貯存設施應防止廢棄物飛散、溢流、滲出 | 感染性廢棄物暫存室設計 |
| 第5條 | 感染性廢棄物貯存場所應上鎖管制、通風良好 | 暫存室管理要求 |
| 第6條 | 廢棄物貯存時限：一般事業廢棄物最長30日；感染性廢棄物最長30日 | 月清運頻率依據 |
| 第7條 | 清除作業應使用密閉車輛，防止散逸 | 委外清運合約要求 |
| 第17條 | 感染性廢棄物處理方式：高溫滅菌、焚化 | 合法處理機構選擇依據 |

### 2.3 感染性事業廢棄物清除處理及標示方法

| 條號/規定 | 條文重點 | 本院對應措施 |
|---------|---------|------------|
| 第2條 | 感染性廢棄物定義：含病原體之固體廢棄物（含針扎、手術廢棄物、病理廢棄物）| 分類標準依據 |
| 第3條 | 容器標示要求：「感染性廢棄物」字樣、生物危害標誌（橘色）、產生機構名稱 | 容器管理要求 |
| 第4條 | 針扎廢棄物須使用防刺穿容器（耐穿刺、防漏、可密封）| 黃色鋼製容器採購依據 |
| 第6條 | 感染性廢棄物不得與一般廢棄物混合 | 分類管理嚴格執行依據 |
| 第8條 | 感染性廢棄物清運聯單須包含：產生機構、廢棄物種類、重量、處理機構 | 聯單填寫規範 |

### 2.4 有害事業廢棄物認定標準

| 類型 | 認定標準 | 本院涉及廢棄物 |
|------|---------|------------|
| 廢藥品 | 含毒性化學物質或管制藥品之廢藥品 | 過期管制藥品、細胞毒性藥品 |
| 廢化學品 | 腐蝕性、氧化性、易燃性化學品 | 廢顯影液、廢實驗試劑 |
| 含汞廢棄物 | 水銀體溫計、熒光燈管 | 廢棄燈管（如仍有汞燈使用）|
| 廢電池 | 鉛酸、鋰電池等 | 設備廢電池、UPS廢電池 |

## 3. 組織對應

本院依法規要求建立以下管理機制：

| 法規要求 | 本院對應措施 | 負責單位 | 文件依據 |
|---------|------------|---------|---------|
| 廢棄物分類管理 | 三類廢棄物分別容器、分區暫存 | 環安衛室、各科室 | PRO-WASTE 第4章 |
| 感染性廢棄物暫存 ≤ 30日 | 每月安排清運，達80%容量即觸發清運 | 環安衛室 | PRO-WASTE 第5章 |
| 委託合法機構清運 | 每年查核承攬商合法許可證 | 環安衛室 | PRO-WASTE 第4章步驟3 |
| 三聯式聯單管理 | 清運聯單保存5年 | 環安衛室 | PRO-WASTE 第6章 |
| 廢棄物容器標示 | 依感染性廢棄物標示方法規定之容器及標誌 | 環安衛室、各科室 | PRO-WASTE 附錄A |
| 年度申報 | 依廢清法第11條進行年度廢棄物申報 | 環安衛室 | — |

## 4. 合規差異分析

| 法規要求 | 現行狀態 | 差異/風險 | 建議行動 | 優先序 |
|---------|---------|---------|---------|------|
| 廢棄物分類三類 | 待確認各科室執行落實度 | 分類錯誤風險 | 每年執行教育訓練並稽核 | 高 |
| 感染性廢棄物容器標示符合規定 | 待現場查核 | — | 執行現場標示查核 | 高 |
| 三聯式聯單保存5年 | 待確認紙本保存完整性 | 查核文件缺失風險 | 建立電子化存檔系統 | 中 |
| 合法清運機構資格查核 | 待確認最近一次查核時間 | 許可證過期風險 | 每年1月查核一次 | 高 |
| 有害廢棄物認定與申報 | 待確認廢藥品管理程序 | 漏報風險 | 補強廢藥品管理程序 | 中 |
